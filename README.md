# Paperclip – notatki i skrypty

Prywatny magazyn dokumentacji i skryptów pomocniczych do uruchamiania Paperclip
(instalacja zarządzana w WSL, lokalna baza, synchronizacja między komputerami).
To nie jest kod aplikacji. Aplikację instaluje się poleceniem `paperclipai install`.

- `docsMe/` – instrukcje, diagnozy i plan.
- `docsMe/scripts/` – skrypty (`handoff.sh`, `pickup.sh`, `secrets-backup.sh`), nietestowane.

Historia dawnego forka kodu Paperclip jest w historii git (commit `a74d40c` to ostatni stan z kodem).
Nie umieszczaj tu kluczy, plików `.env` ani backupów bazy.
